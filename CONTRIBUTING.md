# Contributing

Thanks for taking the time.

## Before you open a PR

**Most of this repo is generated** from the Viral Swipe File source and is
overwritten on every sync: the manifests, `.mcp.json`, `mcp.json`, `skills/`,
`assets/`, `README.md` and `LICENSE`. A PR against those will be lost.

If one of them is wrong, open an issue saying which file and what is wrong with
it, and it gets fixed at the source.

## What is most useful

- **A skill that leads your assistant astray.** A hook quoted wrong, a figure
  stated without its source video, a library sample presented as the whole
  platform, a question it should have declined. Include the prompt.
- **A tool that disagrees with the site.** If a video's stats differ from its
  page on viralswipefile.com, link the video and say which figure.
- **Install trouble.** Which client, which version, and the error.

Do not include sign-in links, codes or tokens.

## Security

Do not open an issue. See [SECURITY.md](./SECURITY.md).
