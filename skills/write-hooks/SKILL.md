# Write hooks from viral examples

Explicit user instructions take priority over this workflow.

1. **Pin the brief.** What the user sells or posts, who it is for, the
   platform, and the niche. If the niche is unclear, ask, or pick the closest
   one from `list_niches` and say which.
2. **Read the evidence.** `list_videos` in that niche sorted by viral factor
   (20 is a good sample). Add a `format` when the user named one. If the niche
   is thin, read an adjacent niche too and say so.
3. **Name the patterns.** Group the hooks you read into 3 to 5 patterns
   (a question, a bold claim, a "POV:", a list promise, a confession…). For
   each pattern give how many of the videos you read use it and one linked
   example with its hook quoted exactly and its viral factor.
4. **Write.** Write the requested number of new hooks for the user's product,
   each labelled with the pattern it follows. Keep them in the user's voice
   and claims they can stand behind: do not invent results, numbers or
   testimonials for their product.
5. **Keep the line clear.** Library hooks are quotes with links; new hooks
   are your writing. Never present a new hook as one that went viral, and
   never copy a creator's hook word for word as the user's own.

If results carry an `upgrade` line instead of hooks, explain that the plan
leaves hooks out and pass the line on; you can still work from captions you
are shown, formats and creators.
